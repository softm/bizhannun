
# v0.8 상가 시각 상세: 이미지·위치·브랜드 운영회사

사업자한눈 상가 이름 검색 결과의 상세 페이지를 텍스트 목록에서 실제 위치와 출처 중심의 화면으로 개선한다.

## 정보 원칙

- 상가 명부(소상공인시장진흥공단)에는 지점 이름, 도로명·지번 주소, 업종, 위도·경도가 있다. 이 명부 자체에는 사업자등록번호·영업시간·주차·전화·실제 사진이 없다.
- 모든 상가에 주소·업종·원천 좌표와 지도 미리보기를 제공한다. 현재 좌표가 없거나 대한민국 범위를 벗어나면 지도를 감춘다.
- **네이버지도에서 위치 보기**가 기본 지도 행동이며, 앱 내부 미리보기는 OpenStreetMap이다. OpenStreetMap 표시와 외부 연결을 혼동하지 않는다. 네이버 지도 JS API 인증키가 준비되면 내부 지도도 교체한다.
- **이 지점 사진 검색**은 외부 네이버 이미지 검색이다. 사진과 지점의 일치 여부·저작권은 자동 확정하지 않는다. 검색 결과 이미지를 자동 저장하거나 임의로 전시하지 않는다.
- 실제 사진을 확보하지 못한 업체는 실사진이 없다고 표시한다. 다른 업체 사진, 업종용 스톡사진을 해당 지점 사진처럼 표시하지 않는다.
- 현재 소규모 검수 사례인 스타벅스는 Wikimedia Commons 공공영역 사진을 **서울 다른 지점의 예시 사진**으로만 사용하며, 사진 안의 매장이 선택한 지점은 아니라는 문구를 이미지 위에 표시한다. 원본: https://commons.wikimedia.org/wiki/File:Starbucks_in_Seoul_South_Korea.jpg (BrianAdler, Public Domain, 2008).
- 스타벅스 브랜드 운영회사 **주식회사 에스씨케이컴퍼니**와 공식 사이트에 표시된 사업자번호 **201-81-21515**, 공식 고객센터 **1522-3232**를 각각 브랜드 공개자료로 표시한다. 근거: https://www.starbucks.co.kr/index.html. 이는 개별 지점의 번호나 지점 직접 연락처가 아니며, 별도 번호 연결을 확정하지 않는다.
- **운영회사 등록 상태 확인** 버튼은 회사 번호 조회로 이동하고, 원래 상가 검색으로 돌아갈 수 있다. 지점에 국세청 상태를 덮어씌우지 않는다.
- 현재 등록정보 확대는 스타벅스 **브랜드 한 건의 공식 근거**이며, 임의의 업체명을 매칭해 회사 번호를 생성하지 않는다. 전국 사업자번호 역조회나 전 업종 매장 사진 확보를 의미하지 않는다.

## 다음 단계

1. 원천별 상호·지점·주소를 기반으로 장소 ID를 확보하는 정확도 검증 파이프라인.
2. 사진 제공자 이용약관과 전송·캐시 제한을 확인하고 상호·주소·좌표 일치 조건을 충족하는 지점 사진만 보여주는 연결.
3. 상호→번호 탐색: 공정위 통신판매업·DART 공시·공식 사이트를 각 원천 조건에 맞게 연결하고 식별 증거, 갱신 시각과 취소 가능한 수동 연결을 보관.
4. 네이버지도 JS API 클라이언트 ID가 준비되면 내부 지도 전환, 기존 외부 길찾기는 유지.
5. 번호 없는 상가 관심목록 저장 및 검색 결과 카드의 사진 미리보기 확대.
