# 사업자 통합정보 수집·정보화

기준일: 2026-10-21. Vercel 없이 GitHub Actions가 공개 웹·등록자료를 수집하고 Pages는 출처가 붙은 결과를 표시합니다. 국세청 상태조회와 Firebase 저장은 기존 직접 연결을 유지합니다.

## 반영한 기능

| 항목 | 구현과 현재 범위 |
| --- | --- |
| 통합 정보 화면 | 상호·법인명, 주소, 업태·종목·업종, 업무 연락처, 웹사이트, 사업 소개·제품, 실제 제공되는 추가 필드 |
| 출처와 동일성 | 사업자번호 정확 일치 또는 확인된 공식 도메인만 개요에 채택. 검색·SNS·채용 링크는 후보로 구분 |
| 상충 정보 | 다른 값과 각 출처를 보존하고 화면에서 확인 |
| 공식 웹 수집 | 공개 HTML·Organization JSON-LD·회사소개·연락처 페이지. 홈페이지당 최대 4페이지, robots·DNS·리디렉션 검사 |
| 외부 채널 | 공개 페이지에 연결된 채용·뉴스·SNS 링크와 허용되는 검색 RSS 결과를 후보로 수집. 검색 링크만 제공하는 버튼은 수집자료라고 표시하지 않음 |
| 고용·산재보험 | 사업자번호 기반 어댑터·페이지 처리·상태 표시 구현. 별도 활용승인이 있어야 실제 자료 반환 |
| 공정위 통신판매 | 기존 어댑터를 Actions 수집에도 연결. 별도 FTC_SERVICE_KEY 필요 |
| 저장·이용 | 수집 JSON 다운로드, 출처를 포함한 거래처 메모 가져오기. 사용자가 저장을 누르면 기존 계정/기기 보관 방식으로 저장 |
| 갱신 | 기존 Pages 일정인 매일 06:17 한국 시간, 수동 실행, 운영자 계정의 공개 수집 요청 |

초기 연결 자료는 사용자가 제시한 사업자번호의 비즈노 공개 상호·주소·업종·사업장 전화, 공식 NAVER 홈페이지 정보입니다. 민간 재가공 자료는 정부가 직접 검증한 정보로 표시하지 않습니다. 대표자 개인 이름은 초기 자료에서 제외했습니다. 최초 자료는 공개 페이지를 직접 읽어 검토한 스냅샷이며, 후속 수집이 실패하면 마지막 성공 자료와 수집 실패 상태를 함께 남깁니다.

## 새 사업자 자료 수집

앱의 사업자 조회 결과 아래 `웹 정보 수집 요청` → 상호·공개 웹사이트(선택) → `공개 요청 작성 화면 열기`에서 내용을 확인하고 제출합니다. 입력된 사업자번호·상호·웹사이트는 공개 요청으로 기록되므로 내부 메모나 비공개 연락처를 입력하지 않습니다.

저장소 소유자·협업자·조직 구성원의 `[사업자 수집]` 요청은 자동 수집합니다. 일반 외부인의 요청은 자동 실행하지 않으며 운영자가 확인한 뒤 Actions 수동 실행으로 처리합니다. 사용자 입력을 shell 명령으로 실행하거나 제안된 도메인을 자동으로 공식 사이트로 인정하지 않습니다.

[수동 실행](https://github.com/softm/bizhannun/actions/workflows/pages.yml)은 사업자번호·상호·웹사이트 입력을 지원합니다. 번호를 비우면 등록 대상 전체를 갱신합니다. 웹사이트가 없으면 공개 사업자 디렉터리의 해당 번호 페이지를 시작점으로 시도하며, 접근 제한·누락은 정상정보 없음과 구분합니다.

## Secrets와 보관

- NTS_SERVICE_KEY: 기존 국세청 브라우저 직접 조회용. 사용자가 선택한 방식대로 배포 파일에서 확인 가능합니다.
- BUSINESS_PUBLIC_SERVICE_KEY: 근로복지공단 수집용. 미등록 시 기존 일반키를 시도하되, 별도 서비스 미승인 오류는 그대로 표시합니다.
- FTC_SERVICE_KEY: 공정위 수집용. Actions에서만 사용하며 브라우저 번들에 주입하지 않습니다.
- SNS Client Secret·Firebase Admin 개인키·검색서비스 Secret은 공개 정적 파일에 넣지 않습니다.

`config/business-sources.json`은 명시적으로 등록한 공개 수집 대상입니다. Firestore의 개인 거래처 목록·메모를 자동으로 읽어 공개하지 않습니다. `data/enrichment/index.json`에는 업무상 공개 사실·출처·시각·상태만 저장합니다. 접근 제한·로그인·유료벽을 우회하지 않으며 웹 원문·사진·리뷰 전체를 재게시하지 않습니다.
