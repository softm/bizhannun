# 사업자한눈 v0.9 — 업체 식별 및 상세자료 연결 구현 계약

작성: 2026-10-29. 기준: v0.8. 이 문서는 구현 착수 및 검수 계약이며, 미구현 기능을 완료로 표시하지 않는다.

## P0 데이터 파이프라인
1. SEMAS 상가 ID를 기준으로 원천 이름·지점·주소·좌표·기준일을 보존한다.
2. 장소 제공자 검색은 서버 측 또는 허가된 공식 API로 수행한다. 상호·지점·주소·좌표의 후보를 수집하고 제공자 place ID, 출처 URL, 확인 시각, 이용허락 범위를 보관한다.
3. 사업자번호 후보는 공정위 통신판매업, DART 기업개황, 공식 홈페이지 등 허용된 원천에서만 찾는다. 사업자번호와 상호가 같아도 동일 사업자로 자동 확정하지 않는다.
4. 매장·운영회사·법인·브랜드는 별도 엔티티로 유지한다. 운영회사 번호를 지점 번호로 승격하지 않는다.
5. 사진은 지점 식별·저작권·캐시 및 재배포 허용 여부가 모두 충족된 경우에만 이미지로 노출한다. 그 외에는 출처로 이동하는 링크와 미확보 상태를 표시한다.
6. 각 필드는 value, sourceUrl, observedAt, sourceDate, evidenceType, matchStatus, entityScope, licenseStatus를 갖는다. 실패 시 이전 정상 자료의 시각을 유지한다.

## P0 UI
- 지점명, 지점 사진(검증된 경우), 지도, 영업시간, 전화, 시설, 사업자 정보, 출처를 구분한다.
- 확인된 정보 / 후보 / 미확보를 명시한다. 정보가 없을 때 사업자번호 입력을 필수 경로로 만들지 않는다.
- 상호 검색 결과는 사진 썸네일이 검증된 경우에만 보여준다. 기본 지도 링크는 유지한다.
- 사업자번호 발견은 '공개자료에서 찾은 번호'로 설명하고 원천과 회사·지점의 범위를 보여준다.

## 구현 순서
| 순서 | 작업 | 완료 조건 |
|---|---|---|
| 1 | v0.8 운영·이미지·지도 검수 | 실제 브라우저·모바일 검증 기록 |
| 2 | 후보 수집 어댑터 및 엔티티 스키마 | 다른 지점·동명 업체 오연결 테스트 |
| 3 | 장소 데이터 제공자 연동 | 실제 지점 5개 이상 성공·실패·출처 확인 |
| 4 | 상호→번호 원천 연동 | 공식 원천에서 실제 후보 응답 및 검증 |
| 5 | 통합 상세 UI | 검증된 필드만 표시, 출처·시각·권리 상태 표기 |
| 6 | Actions 갱신과 data-status | 마지막 시도/성공, 원천 기준일, 오류 구분 |
| 7 | PR·회귀·Pages 배포 | CI 성공, 실제 운영 코드 및 화면 대조 |

## 차단 조건
- 비공개 인증키를 정적 빌드에 주입하지 않는다. 기존 NTS 직접 호출 구조는 보안 검토 대상으로 분리한다.
- API 계약·이용약관·호출한도·사진 재사용권한 확인 전 수집기를 운영 활성화하지 않는다.
- 번호 추정, 매장 사진 오연결, 실패를 폐업으로 해석하는 동작은 배포 차단 사유다.
