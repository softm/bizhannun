# 거래처 상세 모달

Stitch 프로젝트 `12315243263796897623`의 화면 `2915ce3088ef4a15bbe4f7e5f9fb7792`를 기반으로 거래처 상세를 개편했습니다. [원본 HTML·화면·이미지](design/stitch/README.md)를 함께 보관합니다.

## 사용 흐름

거래처 관리에서 저장된 거래처의 상세를 열면 기업 이름, 사업자등록번호, 상태와 상호의 출처를 확인할 수 있습니다. 번호 복사, 조회 기록 저장, 인쇄·PDF 저장을 헤더에서 실행하고, 상태 다시 조회와 메모 편집을 하단에서 실행합니다.

| 탭 | 제공하는 내용 |
| --- | --- |
| 기본 정보 | 등록 상태·과세유형·공개정보 확인 범위, 출처가 확인된 상호·대표자·업태·종목·주소·업무용 전화·웹사이트, 다음 확인 행동 |
| 상태·과세 | 국세청 실제 응답의 상태·과세유형·조회 시각·폐업일·과세유형 전환일, 등록정보 대조로 연결 |
| 조회 이력 | 해당 사업자번호의 실제 조회 기록 최대 50개, 성공·실패와 같은 출처의 성공 응답 간 변화 구분 |
| 공개정보·출처 | 수집한 웹·공공 자료, 출처 링크·수집 시각, 후보·누락·출처별 차이, 저장본과 최신 공개 수집본의 값 차이 |
| 메모·태그 | 저장 공간 안내, 메모·태그 편집·저장·되돌리기, 관리용 이름 등 기존 거래처 정보 편집으로 연결 |

## 저장과 비동기 동작

- 메모는 최대 5,000자, 태그 입력은 최대 500자·중복 제거 후 10개입니다. 쉼표·세미콜론·세로 막대로 구분합니다. 제한 초과 시 내용을 잘라 저장하지 않고 오류를 안내합니다.
- 로그인하면 기존 UID별 Firestore 저장 경로를, 비로그인이면 해당 브라우저의 IndexedDB 저장 경로를 사용합니다. 기존 저장 확인·충돌 처리를 유지합니다.
- 메모 저장은 최신 거래처의 메모·태그·수정 시각만 바꿉니다. 사업자번호, 공개정보, 이름 출처, 조회·변경 이력은 보존합니다.
- 저장 도중 추가로 입력한 내용은 미저장 초안으로 남깁니다. 저장 완료 응답이 늦게 도착하더라도 새 입력을 이전 제출 내용으로 덮어쓰지 않습니다.
- 탭 이동·상태 재조회·공개자료 갱신·창 닫기 후 같은 거래처 다시 열기에서 초안을 유지합니다. 초안은 현재 페이지 메모리에만 있으며, 새로고침·탭 종료 시 브라우저의 미저장 변경 확인을 사용합니다.
- 계정 전환, 성공한 백업 복원 및 거래처 삭제는 관련 초안을 정리합니다. 다른 계정으로 늦게 도착한 저장 응답은 적용하지 않습니다.
- 저장 중·상태 조회 중·계정 연결 중을 구분해서 표시합니다. 중복 저장·재조회를 차단하면서 메모 입력은 유지합니다.
- 한글 조합 입력 중에는 상세 DOM 교체를 늦춥니다. textarea의 줄바꿈 정규화와 첫 줄바꿈 처리 때문에 원문이 유실되거나 변경하지 않은 메모가 수정됨으로 표시되지 않도록 처리합니다.

## 조회 결과와 보고서

최근 조회가 실패하면 직전 성공 기록과 그 시점을 명시합니다. 조회 실패를 폐업으로 바꾸거나 새로운 상태 변화로 기록하지 않습니다. 공개정보는 정확히 같은 사업자번호의 자료만 연결하며, 사용자 별칭과 공개 상호를 구분합니다.

`조회 기록 저장`은 출처·시각·상태·공개정보·조회 이력을 포함한 독립 HTML 파일을 만듭니다. 인쇄 버튼도 같은 내용의 별도 문서를 인쇄하므로 브라우저에서 PDF로 저장할 수 있습니다. 기본 내보내기와 인쇄에는 내부 메모, 태그와 관리용 별칭을 포함하지 않습니다. 이 기록은 앱이 정리한 조회 결과이며 국세청 발급 증명서가 아닙니다.

원본 디자인의 가상 신용평가, 공제 가능 판정, 실시간 자동 감시, 카카오·이메일 알림, 계좌 실명조회는 제공하지 않습니다. 실제 확보한 사실과 지원하는 행동만 표시합니다.

## 접근성과 화면 크기

다이얼로그의 제목·탭·패널 관계를 연결했고, 배경을 비활성화합니다. Tab 키는 현재 보이는 모달 안에서 순환합니다. 좌우 화살표·Home·End로 탭을 이동하며 Escape로 닫을 수 있습니다. 갱신 중에도 포커스를 모달 안에 유지하고 닫으면 이전 요소로 돌려줍니다.

데스크톱에서는 헤더·탭·작업 푸터가 고정되고 내용만 스크롤됩니다. 600px 이하에서는 화면에 맞춰 카드가 한 열로 배치되고 탭 목록은 가로로 스크롤됩니다. 키보드 포커스와 동작 축소 설정을 지원합니다.
